# hour / candle-replay

An endless candlestick strip on one canvas: a seeded random walk with drifting trend and volatility, green buy arrows with "buy" labels, dashed red stop lines with "stop" labels, take-profit / stop / time exits marked with green or red arrows, an auto-scaling price window, an old-tape fade on the left and a glowing playhead. It scrolls at about 1.1 candles per second and slows to 0.4 when the kill switch is thrown.

## Reuse
Copy this folder plus `engine.js`, `core.js`, `base.css`; add the html and call `JEV.boot()`. Standalone page: `node jev/build-components.mjs --only hour/candle-replay`.

- keep a `<div class="hr-tape"><canvas id="hr-tape"></canvas></div>` (the canvas fills its box; set the box height in CSS).
- tune: `T.pitch` / `T.bw` (candle spacing and width, set in `layoutT`), the speed in `drawT` (`dt * 1.1`), the seed `J.rng(4100)`.

## Data it consumes
Bus `kill` only (speed). The candles are generated by `genCandle()` into ring buffers `tO tH tL tC` (open, high, low, close, 512 deep); trades are `{i0, i1, entry, stop, tp, exit, win, why}`.

## Swapping in real data
Fill `tO/tH/tL/tC` from a real OHLC feed (index `i & 511`), push your own trade objects into `trades`, advance `gi` per candle and keep `T.pos` as the playhead candle index.

Everything shown is a simulation.
