JEV components

Every section and chart of the JEV Desk as a standalone page. Open one, or copy its folder: component.html + component.css + component.js + component.json and the shared runtime (engine.js, core.js, base.css). All data is simulated.

builds

Build cardbuilds / build-card

A reusable build card with a typed-question tag, live answer, confidence sparkline against the floor line and a hover-tilt glass look, shown as a grid of four accent variants.

JEV core cardbuilds / core-card

The glass JEV system-one card: a spinning pink rim, pulsing halo and rings, a holographic JEV wordmark that tilts with the pointer, a live action chip and last-answer line.

The whole "ten builds, one decision layer" section: head with live stats, the particle hub, the circuit traces and all six live dashboard tiles.

Builds hubbuilds / hub

The full decision hub: a glass JEV core card fed by ten build cards through particle ribbons, then three typed questions, five answers and the hard-rules row, all live from the simulated decision stream.

Particle ribbonsbuilds / ribbons

Glowing particle ribbon streams flowing between two boxes: additive particles with trails, comets and bursts that fire on each decision, boost on hover and freeze red under the kill switch.

What code owns tilebuilds / tile-code-owns

Five bars for the things plain code holds (the menu, thresholds, orders, the stop, the log); the stop turns red under the kill switch.

Cost this run tilebuilds / tile-cost

A serif odometer showing the simulated running cost of all typed answers, with decisions count, cost each and a zero-token line.

Decision stream tilebuilds / tile-decision-stream

A live list of the newest decisions from every build with primitive tag, action, confidence and the gate result (execute, review or skip).

Latency by build tilebuilds / tile-latency

Ten animated latency bars, one per build, coloured by typed question, with the row of the build that just answered lighting up.

Primitive mix tilebuilds / tile-primitive-mix

How many of the answers were choices, flags or scores, as odometer counters with proportional glowing bars.

Where it runs tilebuilds / tile-where-it-runs

Three rows of ten squares show how many builds run on the api, on a laptop and on a gpu box; the api squares ping on every decision.

Dashboard tilesbuilds / tiles-all

The six live dashboard tiles together: decision stream, latency by build, cost this run, primitive mix, where it runs and what code owns.
